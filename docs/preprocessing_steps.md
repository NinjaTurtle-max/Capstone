- 작성: 2026-10-07 (상태는 같은 날 15:56 기준)

## 원칙

- 원본 값은 보존하고, 이상치는 **삭제하지 않고 표시(flag)** 한다. 계획서와 기초분석 모두 0값·고농도 자동 삭제 금지, 정답 결측 보간 금지를 정했다.
- 표시·제외 임계값은 검증 분할을 먼저 고정한 뒤 **훈련 자료로만** 정한다. 이 문서는 임계값 숫자를 정하지 않는다.

## 3. 에어코리아 — 데이터 엔지니어 담당

참고: 연구 측이 만든 월별 parquet(`data/airkorea/`, `scripts/prep_airkorea.py`)에 단위·시각·결측 표시·이중 기재 표시가 들어 있다. 60/60개월, 기초분석과 행 수·측정소 수·물질별 유효/빈칸/합계가 일치한다.

| 단계 | 처리 | 근거 | 상태 |
| --- | --- | --- | --- |
| 단위 | ppm × 1000 → ppb | §3.1 | 완료 (참고용 parquet) |
| 시각 | 24시 → 다음 날 00시, KST → UTC | 기초분석 | 완료 |
| 평균 구간 | 시각 표기가 1시간 평균의 시작인지 끝인지 | §4.6 | 사양 확인 필요 |
| 결측 구분 | 빈칸 / −999 / 음수 구분은 완료(NO₂의 −999·음수 0건). 행이 아예 없는 경우는 개설 전·폐쇄 후인지 장비 결측인지 구분 | 기초분석 | 부분 완료 — 나머지는 운영 이력 필요 |
| 이중 기재 | 2023–24년 측정소 4곳의 국가배경·교외대기 이중 기재. 표시 완료(140,352행 = 70,176쌍, 값 충돌 0) | 정답이 두 번 학습되는 것 방지 | 결정 필요 (한 번만 세는 규칙) |
| 측정소 메타 | 좌표, 운영 시작·종료, 이전 이력 | 위성·격자 정합, 공간 블록 검증 | **자료 없음** |
| **이상치: 값** | 물리 범위 밖, 0값(연 245–1,569건), 고농도(100 ppb 초과 연 83–493건) | 0값·고농도는 원값 유지 | 결정 필요 (표시 기준) |
| **이상치: 시계열** | 같은 값이 계속 이어짐(센서 고착), 급등 후 바로 복귀, 0이 계속 이어짐 | 장비 이상 패턴 | 결정 필요 (훈련 자료로 기준) |
| **이상치: 공간** | 주변 측정소와 크게 다른 값. **표시만 한다.** 도로변(24.7 ppb)·항만은 실제로 도시대기(13.9 ppb)와 다르다 | §4.1 | 결정 필요 |
| 측정 분해능 | 2023년부터 1 ppb → 0.1 ppb 단위로 바뀜. 1 ppb 단위가 아닌 값 비율 5.5 / 7.4 / 7.5 / 61.4 / 88.2% (2020→2024, 기초분석과 parquet 두 방법으로 세어 일치) | 연도 간 비교 | 기록 완료, 단위 통일 여부 결정 필요 |
| 측정망 선별 | 도시대기를 주 분석으로, 도로변·항만·배경은 민감도 분석으로 할지 | §5 | 결정 필요 |
| 측정소 포함 기준 | 최소 유효율. **훈련 연도 자료로만 정한다.** 기초분석의 고정패널 90% 기준은 전 연도를 썼으므로 그대로 쓰면 누출 | §4.9 | 결정 필요 |
| 출처 기록 | 최종확정 자료 여부, 내려받은 시점 | 계획서 S3 | 사양 확인 필요 |
| 필요 항목 | 필수: NO₂, 결측 구분, 측정 시각, 측정소 코드·좌표·망·운영 이력, 이중 기재 규칙. 선택: O₃(주변 측정소 입력용). 불필요: CO·SO₂·PM10·PM2.5 | 격자 지점에 없는 값은 주 입력 불가 | — |

## 4. ASOS/AWS — 데이터 엔지니어 담당

용도는 **ERA5 바람 검증**이다(계획서 §4.4). 주 모델 입력이 아니다.

| 단계 | 처리 | 상태 |
| --- | --- | --- |
| 지점 메타 | 지점 번호, 좌표, 해발고도, 풍속계 설치 높이, 이전 이력 | 사양 확인 필요 |
| 시각 | KST → UTC, 정시 풍속을 몇 분 평균으로 내는지 | 사양 확인 필요 |
| 품질 | 기상청 품질검사 표시 반영 | 사양 확인 필요 |
| 풍향 규약 | 정온 표기 방식, 기상학적 풍향(불어오는 방향) → u·v로 바꿀 때 부호 | 사양 확인 필요 |
| 이상치 | 범위 밖, 같은 값 계속 이어짐, 급변을 표시 | 결정 필요 |
| ERA5와 비교 | 격자값 보간 방식, 높이 차(10 m vs 풍속계 높이) | 결정 필요 |

## 5. 공통 — 정합과 누출 방지

| 단계 | 처리 | 상태 |
| --- | --- | --- |
| 시간 축 | UTC 하나로 통일. KST·지방태양시는 파생 변수로만 | 원칙 |
| **분할 먼저** | 검증 분할을 고정한 뒤 임계값·표준화·결측 대체를 훈련 분할로만 학습 | 결정 필요 (분할 방식) |
| 추세 고려 | 2020→2024 NO₂ 평균이 22% 감소(16.1 → 12.6 ppb, 고정패널 271곳은 15.9 → 12.6 ppb로 21% 감소). 분해능도 2023년에 바뀜. 2024년만 시험으로 떼면 추세 항 없이는 편향이 생김 | 결정 필요 |
| 정답 결측 | 평가에서 제외하고 보간하지 않음 | 원칙 |
| 대상 측정소 입력 금지 | 예측 대상 측정소의 동시 관측(NO₂·O₃ 등)은 입력하지 않음. 보류 측정소는 주변 입력·시차·그래프에서도 제외 | 원칙 (§4.9) |
| 측정소–픽셀·격자 정합 | 2024는 픽셀 안에 드는지 판정, 2020–23은 픽셀 경계가 없어 최근접 중심 + 거리 기록. 같은 픽셀을 공유하는 측정소 기록 | 담당 미정, 좌표 필요 |
| 위성 결측 변수 | 일별 유효 표시, 마지막 유효 관측 이후 경과 시간 | 정합 단계 |
